# Large geospatial raster data

**[Download the complete MMFR raster package from Google Drive](https://drive.google.com/drive/folders/12xsJ0O_-dnXbGPHxIg4j85hOWCGSSPj6?usp=sharing)**

The public raster package contains **19 GeoTIFF files** organized into:

1. `01_Core_Derived_Products`
2. `02_RF_Hard_Class_Maps`
3. `03_Predictor_Stacks`
4. `04_Landsat_Composites`

See `raster_manifest.csv` for file-level descriptions, sizes and provenance.

The GeoTIFF files are stored outside GitHub to avoid repository file-size
limitations. The scientific notebook, lightweight tabular inputs, figures,
maps and metadata remain version-controlled in this repository.
