# Data structure

- `analysis_inputs/`: lightweight tabular inputs used by the Colab/Python analysis.
- `external_agreement/`: repeated exact-year CGMD product-agreement data.
- `external_rasters/`: manifest and access information for large GeoTIFF products.
- `metadata/`: reproducibility and final analysis metadata.

CGMD comparisons are external product agreement, not field-ground-truth accuracy.
